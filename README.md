# Skills da StackLab

Este repositório reúne skills abertas para ajudar agentes de IA a trabalhar com produtos e projetos da StackLab.

## Skills disponíveis

### `stacklab-modules`

Ajuda agentes a planejar, criar, revisar e validar módulos de navegador para o Kanban StackLab, seguindo a documentação e os exemplos públicos de [StackLabModulos](https://github.com/StackLab-Digital/StackLabModulos).

Arquivo: [`skills/stacklab-modules/SKILL.md`](skills/stacklab-modules/SKILL.md)

## Como usar

Copie a pasta da skill desejada para o diretório de skills do seu agente, seguindo o formato aceito pela plataforma. Cada `SKILL.md` informa quando deve ser usada e quais instruções aplicar.

## Contribuições

Issues e pull requests são bem-vindos. Inclua fontes verificáveis para convenções específicas da StackLab e deixe claras as limitações que dependem da versão do Kanban ou do ambiente.
